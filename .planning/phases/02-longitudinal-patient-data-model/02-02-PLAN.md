**Public entry point — `promote_to_patient_tables(doc_id: str, user_id: str, structured_result: StructuredResult | None, upload_date: str | None = None) -> None`:**
- If `structured_result is None`, return immediately.
- Wrap everything in try/except per D-04/D-05/D-07. On exception: `_log.warning("patient_store promotion failed doc_id=%s: %s", doc_id, exc)` and return.
- Get `client = _get_client()`.
- Read `family = structured_result.document_family` and `data = structured_result.structured_data`.
- Dispatch: `structured_lab` -> `_promote_lab(client, doc_id, user_id, StructuredLab(**data), upload_date)`, `clinical_narrative` -> `_promote_clinical(client, doc_id, user_id, ClinicalNote(**data))`, `medication_document` -> `_promote_medications(client, doc_id, user_id, MedicationDocument(**data))`, `imaging_narrative` -> `_promote_imaging(client, doc_id, user_id, ImagingReport(**data))`. Unknown families: skip silently.

**Alias lookup — `_load_aliases(client) -> dict[str, str]`:**
- `res = client.table("analyte_aliases").select("raw_name,canonical_name").execute()`
- Return `{row["raw_name"].lower(): row["canonical_name"] for row in (res.data or [])}`
- Wrap in try/except returning `{}` on failure (table may not exist yet).

**Normalization — `_normalize_analyte(raw: str, aliases: dict[str, str]) -> str`:**
- `return aliases.get(raw.strip().lower(), raw.strip().lower())`

**Date parsing — `_parse_br_date(date_str: str | None, fallback: str | None = None) -> str | None`:**
- Try `datetime.strptime(date_str, "%d/%m/%Y").strftime("%Y-%m-%d")`.
- On any error, try `datetime.strptime(date_str, "%Y-%m-%d").strftime("%Y-%m-%d")` (already ISO).
- On any error, return `fallback`.
- If `date_str is None`, return `fallback`.

**Observation upsert — `_promote_observation(client, user_id: str, doc_id: str, normalized_analyte: str, raw_analyte: str, finding: LabFinding, observed_date: str | None) -> None`:**
Per D-01 conflict detection:
1. Query existing: `client.table("patient_observations").select("id,value_str,unit").eq("user_id", user_id).eq("normalized_analyte", normalized_analyte).eq("observed_date", observed_date).execute()`
2. If `existing.data` is non-empty:
   a. Get `ex = existing.data[0]`
   b. If `ex["value_str"] == finding.value and ex["unit"] == finding.unit` -> return (no-op, identical)
   c. Else -> insert NEW row with `needs_review=True` (conflict)
3. If no existing row -> insert new row with `needs_review=False`
4. Row dict: `{"id": str(uuid.uuid4()), "user_id": user_id, "document_id": doc_id, "normalized_analyte": normalized_analyte, "raw_analyte": raw_analyte, "value_str": finding.value, "unit": finding.unit, "reference_range": finding.reference_range, "flag": finding.flag, "observed_date": observed_date, "needs_review": needs_review}`
5. Insert via `client.table("patient_observations").insert(row).execute()`

**Lab promotion — `_promote_lab(client, doc_id: str, user_id: str, lab: StructuredLab, upload_date: str | None) -> None`:**
1. `aliases = _load_aliases(client)` (one call per document, not per finding)
2. `observed = _parse_br_date(lab.collection_date, fallback=upload_date)`
3. For each `finding in lab.findings`:
   - `normalized = _normalize_analyte(finding.name, aliases)`
   - `_promote_observation(client, user_id, doc_id, normalized, finding.name, finding, observed)`

**Clinical promotion — `_promote_clinical(client, doc_id: str, user_id: str, note: ClinicalNote) -> None`:**
1. For each `dx in note.diagnoses`:
   - Upsert into `patient_conditions` with `on_conflict="user_id,normalized_condition"`:
     `{"id": str(uuid.uuid4()), "user_id": user_id, "document_id": doc_id, "raw_condition": dx, "normalized_condition": dx.strip().lower(), "clinical_status": "active", "verification_status": "confirmed"}`
2. For each `dx in note.suspected_diagnoses`:
   - Same upsert but `clinical_status="suspected"`, `verification_status="provisional"`
3. For each `allergy in note.allergies`:
   - Upsert into `patient_allergies` with `on_conflict="user_id,normalized_allergen"`:
     `{"id": str(uuid.uuid4()), "user_id": user_id, "document_id": doc_id, "raw_allergen": allergy, "normalized_allergen": allergy.strip().lower(), "reaction": None}`
4. For each `med in note.medications` (these are plain strings, not MedicationEntry):
   - Upsert into `patient_medications` with `on_conflict="user_id,normalized_medication"`:
     `{"id": str(uuid.uuid4()), "user_id": user_id, "document_id": doc_id, "raw_medication": med, "normalized_medication": med.strip().lower(), "dose": None, "route": None, "frequency": None, "status": "active"}`

**Medication promotion — `_promote_medications(client, doc_id: str, user_id: str, med_doc: MedicationDocument) -> None`:**
1. For each `entry in med_doc.medications` (these ARE MedicationEntry objects):
   - Upsert into `patient_medications` with `on_conflict="user_id,normalized_medication"`:
     `{"id": str(uuid.uuid4()), "user_id": user_id, "document_id": doc_id, "raw_medication": entry.name, "normalized_medication": entry.name.strip().lower(), "dose": entry.dose, "route": entry.route, "frequency": entry.frequency, "status": "active"}`

**Imaging promotion — `_promote_imaging(client, doc_id: str, user_id: str, report: ImagingReport) -> None`:**
1. Single insert into `patient_imaging_findings`:
   `{"id": str(uuid.uuid4()), "user_id": user_id, "document_id": doc_id, "modality": report.modality, "body_region": report.body_region, "impression": report.impression, "urgency": report.urgency}`
2. Use plain `insert` (no upsert — imaging findings have no natural dedup key per D-13).

IMPORTANT: For all upsert calls, use NO spaces in `on_conflict` value (per Pitfall 4 in research). Example: `on_conflict="user_id,normalized_condition"` not `on_conflict="user_id, normalized_condition"`.
