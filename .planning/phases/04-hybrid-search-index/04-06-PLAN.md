Implementation steps:

1. Import `recreate_index` from `scripts.setup_azure_search` (or import the schema creation logic directly).
2. Import `assemble_context_block` from `services.rag.context_block`.
3. Import `generate_embedding` from `services.azure.embeddings`.
4. Import `index_document` from `services.azure.search`.
5. Import `StructuredResult` from `models.document`.

6. `def fetch_all_documents() -> list[dict]`:
   - Use Supabase client: `create_client(os.environ["SUPABASE_URL"], os.environ["SUPABASE_SERVICE_KEY"])`
   - Query: `supabase.table("documents").select("id, user_id, anonymized_text, original_name, structured_result").not_.is_("anonymized_text", "null").execute()`
   - Return `response.data`

7. `def reindex(dry_run: bool = False) -> None`:
   - Step 1: If not dry_run, call `recreate_index()` to drop+recreate index.
   - Step 2: Fetch all documents via `fetch_all_documents()`.
   - Step 3: For each document:
     a. Parse `structured_result`: if doc["structured_result"] is not None, construct `StructuredResult(**doc["structured_result"])`. Wrap in try/except (some old docs may have incompatible schemas).
     b. Assemble context block: `assemble_context_block(sr, doc["anonymized_text"])`.
     c. Generate embedding: `generate_embedding(context_block)` (returns None on failure).
     d. Extract metadata: `document_family`, `collection_date`, `document_subtype` from the StructuredResult if available.
     e. Extract entities: if structured_result has `entities_for_memory`, use those; else empty list.
     f. If dry_run: print summary line and continue.
     g. Call `index_document(doc_id=doc["id"], user_id=doc["user_id"], text=doc["anonymized_text"], source_name=doc.get("original_name", "unknown"), entities=entity_labels, content_vector=embedding, document_family=family, collection_date=coll_date, document_subtype=subtype)`.
   - Step 4: Print summary: total docs, embeddings succeeded, embeddings failed (None returned), docs indexed.

8. Batch upload optimization: instead of calling `index_document()` one-by-one, accumulate document dicts and use `SearchClient.upload_documents()` in batches of 100 for performance. Build the document dict the same way `index_document()` does (conditionally exclude `content_vector` when None per Pitfall 2).

9. `if __name__ == "__main__":` block with argparse: `--dry-run` flag.

10. Configure logging: `logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")`.

NOTE on entities: The current `index_document()` expects `entities: list[str]` as labels. For re-index, the entities field in the search index is a concatenated string. For documents where we only have `entities_for_memory` (from structured_result), pass those directly. For documents where we have the full entities from the Supabase `medical_entities` column, that column is not queried here (it would require a separate query or join). Pragmatic approach: use `entities_for_memory` from structured_result as entity labels — this is sufficient for the search index's `entities` field.
