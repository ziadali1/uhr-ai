       ```python
       _CONFLICT_COLS = {
           "patient_medications": "user_id,normalized_medication",

           "patient_allergies": "user_id,normalized_allergen",
       }
       ```

    5. Function `run_migration(user_id: str, dry_run: bool = False, verbose: bool = False) -> dict`:
       - Fetch ALL entries (not just active): `client.table("health_entries").select("*").eq("user_id", user_id).execute()`
       - Convert each row via `_row_to_entry(row)` from health_store
       - For each entry call `_map_entry(entry, user_id)` to get (table, row)
       - If `dry_run`: print what would be upserted, increment counter, do NOT call upsert
       - If not `dry_run`: call `client.table(table).upsert(row, on_conflict=_CONFLICT_COLS[table]).execute()`
       - Track and return `{"total": N, "migrated": N, "errors": N}`
       - Wrap each upsert in try/except, log errors, increment error counter
