**`get_observations_timeline(user_id: str, analyte: str, date_from: str | None = None, date_to: str | None = None) -> list[dict]`**
- Soft-fail wrapper: try/except returning `[]` on error, log warning.
- Inside: `client = _get_client()`
- Build query: `client.table("patient_observations").select("*").eq("user_id", user_id).eq("normalized_analyte", analyte).order("observed_date", desc=True)`
- If `date_from`: chain `.gte("observed_date", date_from[:10])` (slice to 10 chars per Pitfall 4)
- If `date_to`: chain `.lte("observed_date", date_to[:10])`
- Execute query, iterate `res.data or []`, call `_enrich_observation(row)` on each, return list.

**`get_patient_summary(user_id: str) -> dict | None`**
- Soft-fail wrapper returning `None` on error.
- Inside: `client = _get_client()`
- Call `_query_active_conditions(client, user_id)`, `_query_current_medications(client, user_id)`, `_query_allergies(client, user_id)`, `_query_latest_labs(client, user_id)`
- Return `{"user_id": user_id, "active_conditions": conditions, "current_medications": medications, "allergies": allergies, "latest_labs": latest_labs}`

**`get_conditions(user_id: str) -> list[dict]`**

- Query `patient_conditions` table: `.select("*").eq("user_id", user_id).execute()`
- Return `res.data or []`

**`get_medications(user_id: str) -> list[dict]`**

- Query `patient_medications` table: `.select("*").eq("user_id", user_id).execute()`

**`_query_allergies(client, user_id: str) -> list[dict]`** (private)
- `client.table("patient_allergies").select("*").eq("user_id", user_id).execute()`
- Return `res.data or []`

**`_query_latest_labs(client, user_id: str) -> list[dict]`** (private)
- Query: `client.table("patient_observations").select("normalized_analyte,raw_analyte,value_str,unit,reference_range,flag,needs_review,observed_date,document_id").eq("user_id", user_id).order("observed_date", desc=True).execute()`
- Deduplicate: iterate `res.data or []`, use `seen: set[str]` on `normalized_analyte`, keep first (most recent) per analyte.
- Call `_enrich_observation(row)` on each kept row.
- Return list.

**`_enrich_observation(row: dict) -> dict`** (private)
- Start with copy of `row`.
- Map field names for API response: `observed_at = row.get("observed_date")`, `analyte_raw = row.get("raw_analyte")`, `analyte_norm = row.get("normalized_analyte")`
- Parse `value_num`: `try: float(row.get("value_str", ""))` → set value, `except (ValueError, TypeError): None`
- Parse `ref_low`, `ref_high` from `reference_range`: if string contains `-`, split on `-`, try `float()` each part. If parsing fails or no `-`, both `None`.
- Return dict with keys: `observed_at`, `value_num`, `value_str`, `unit`, `ref_low`, `ref_high`, `flag`, `document_id`, `analyte_raw`, `analyte_norm`, `needs_review`
